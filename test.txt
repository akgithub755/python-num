1. optparse → argparse

Before:

python
import optparse
...
parser = optparse.OptionParser(version="%prog " + __version__)
parser.add_option('-c', '--control', dest='control', default=False, help='''Fichier de control''')
parser.add_option('-d', '--database', dest='database', default=False, help='''Base de donnee SQLServer''')
parser.add_option('-s', '--surveys', dest='surveys', default=False, help='''Liste des surveys a extraire''')
parser.add_option('-v', '--versions', dest='versions', default=False, help='''Liste des versions a extraire''')
parser.add_option('-o', '--output-directory', dest='output_directory', default=False, help='''Repertoire ou seront stockes les fichiers extraits''')
parser.add_option('-i', '--last-id-file', dest='lastid_file', default=False, help='''Fichier contenant le dernier id traite''')
parser.add_option('-m', '--mode', dest='mode', default=False, help='''Mode d export (s = synchro (execution DLL), e = export)''')
parser.add_option('-l', '--log-file', dest='log_file', default=False, help='''Fichier Log''')
parser.description = "Export Achats InHome %s" % __version__
options, args = parser.parse_args()

After:

python
import argparse
...
parser = argparse.ArgumentParser(description=f"Export Achats InHome {__version__}")
parser.add_argument('-c', '--control', dest='control', default=False, help='Fichier de control')
parser.add_argument('-d', '--database', dest='database', default=False, help='Base de donnee SQLServer')
parser.add_argument('-s', '--surveys', dest='surveys', default=False, help='Liste des surveys a extraire')
parser.add_argument('-v', '--versions', dest='versions', default=False, help='Liste des versions a extraire')
parser.add_argument('-o', '--output-directory', dest='output_directory', default=False, help='Repertoire ou seront stockes les fichiers extraits')
parser.add_argument('-i', '--last-id-file', dest='lastid_file', default=False, help='Fichier contenant le dernier id traite')
parser.add_argument('-m', '--mode', dest='mode', default=False, help='Mode d export (s = synchro (execution DLL), e = export)')
parser.add_argument('-l', '--log-file', dest='log_file', default=False, help='Fichier Log')
parser.add_argument('--version', action='version', version=f"%(prog)s {__version__}")
options = parser.parse_args()

Note: argparse uses attribute access the same way (options.control, options.database, etc.) so the rest of your code below (lines 493–505) doesn't need to change.

2. codecs.open → built-in open

Before:

python
f = codecs.open(output_file, "w", encoding, 'ignore')

After:

python
f = open(output_file, "w", encoding=encoding, errors='ignore')

You can then remove import codecs entirely if it's not used elsewhere.

3. Parameterized SQL instead of string interpolation

Before:

python
sql = "SELECT lastEntryID FROM psGenSurvey WHERE survey='%s' AND surveyVersion = %s" % (survey, surveyversion)
cursor.execute(sql)

After:

python
sql = "SELECT lastEntryID FROM psGenSurvey WHERE survey=? AND surveyVersion = ?"
cursor.execute(sql, (survey, surveyversion))

Same fix applies to getCount:

Before:

python
sql = "SELECT count(*) FROM psData WHERE survey in (%s)" % (
    ",".join(map(lambda s: "'%s'" % s, surveylist))
)
cursor.execute(sql)

After:

python
placeholders = ",".join("?" for _ in surveylist)
sql = f"SELECT count(*) FROM psData WHERE survey in ({placeholders})"
cursor.execute(sql, surveylist)

And getpsDataVersionCount:

Before:

python
sql = "SELECT survey,surveyVersion,count(*) FROM psData WHERE survey in ('%s') GROUP BY survey,surveyVersion ORDER BY survey,surveyVersion" % (surveys)
cursor.execute(sql)

After:

python
placeholders = ",".join("?" for _ in surveys)
sql = f"SELECT survey,surveyVersion,count(*) FROM psData WHERE survey in ({placeholders}) GROUP BY survey,surveyVersion ORDER BY survey,surveyVersion"
cursor.execute(sql, surveys)

And the big Export() query:

Before:

python
sql = "SELECT %s FROM psData WHERE survey='%s' AND surveylevel>0 AND entryType!='incomplete' AND surveyVersion=%d  %s ORDER BY endtime,surveyLevel,level2pos" % (
    ",".join(columns), survey, surveyversion, lastid_cond
)
cursor.execute(sql)

After:

python
sql = "SELECT {} FROM psData WHERE survey=? AND surveylevel>0 AND entryType!='incomplete' AND surveyVersion=? {} ORDER BY endtime,surveyLevel,level2pos".format(
    ",".join(columns), lastid_cond
)
params = [survey, surveyversion]
if surveyversion in surveyslastid:
    params.append(lastid)
cursor.execute(sql, params)

(Note: lastid_cond still needs its %s/? swapped consistently — since it's built separately as " AND %s > %d" % (lastid_col_name, lastid), either keep the lastid value inline as it's an int derived from your own DB read, not user input, or parameterize it too the same way.)

4. Batch file writes instead of per-row writes

Before:

python
for row in cursor:
    ...
    f.write("%s\n" % (";".join(rowout)))
    nnecrit += 1

After:

python
BATCH_SIZE = 1000
write_buffer = []

for row in cursor:
    ...
    write_buffer.append(";".join(rowout))
    nnecrit += 1
    if len(write_buffer) >= BATCH_SIZE:
        f.write("\n".join(write_buffer) + "\n")
        write_buffer = []

if write_buffer:
    f.write("\n".join(write_buffer) + "\n")

5. f-strings instead of % formatting (readability + minor speed)

Before:

python
return conn, "%s@%s:%s" % (dbuser, dbserver, dbname)

After:

python
return conn, f"{dbuser}@{dbserver}:{dbname}"

Apply the same substitution pattern throughout log_info(...) calls wherever you see "%s" % var — purely cosmetic/perf, low risk, do it opportunistically rather than all at once.
